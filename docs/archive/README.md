# Tài liệu legacy

[EDA report](legacy/eda_report.md) và [EDA summary](legacy/eda_summary.json) là đầu ra lịch sử có dữ liệu fallback/ước lượng. Không sử dụng để nghiệm thu UIT-VSFC hoặc so với kết quả chính thức.

Xem [reports chính thức](../reports/README.md), [trạng thái](../status.md) và [workflow hiện hành](../../ml/README.md). Giữ nguyên các số liệu legacy để truy vết; không sửa chúng thành kết quả thật.
